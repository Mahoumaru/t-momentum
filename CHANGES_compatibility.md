# Compatibility-only, historical-behavior variant (experimental)

Based on the May 2023 source archive of t-momentum. This archive deliberately
preserves the old numerical update rules while adding maintenance fixes.

## Preserved 2023 numerical behavior

- The shared t-momentum weight `state['W_t']` remains at its initialization
  value (the Python-float update is intentionally NOT written back).
- Adaptive-DoF `state['z_ave']` and `state['z_var']` remain at their initialized
  values, while `state['dof']` is recomputed from the temporary statistics.
- TAdamW retains its original epsilon placement and bias-correction ordering,
  rather than being changed to recover modern torch.optim.AdamW exactly.

These are **historical implementation behaviors**, not endorsement of them as
correct relative to the original mathematical derivation.

## Maintenance fixes retained

- Gradient-enabled closure invocation across optimizers.
- Modern `Tensor.add_(other, alpha=...)` signatures.
- Avoid `.data` in TAdamW, TRAdam, TPlainRAdam, TPAdam; dtype preservation
  for FP64 (and FP32 intermediates for FP16/BF16) in those optimizers.
- Prevent TPAdam weight decay from mutating the user-provided gradient.
- Fix broken default `TMomentum` utility construction.
- Correct TRAdam/TPlainRAdam first-step state initialization. **This is an
  exception to strict behavioral equivalence:** finite-k_dof RAdam variants
  previously crashed, so no successful original trajectory exists to preserve.

## Tests / scope

- 44 cases (12 optimizer classes, finite and infinite DoF where supported,
  with fixed or adaptive DoF) were compared against reference trajectories
  generated by the unmodified May 2023 source with PyTorch 2.10 CPU.
- The unmodified finite-DoF TRAdam and TPlainRAdam paths crashed and were
  omitted from historical reference comparison.
- Includes source-archive baseline fixtures and tests. Run:
  `python -m unittest discover -s tests -v`.
- Older torch, GPU, AMP, compilation, and graph capture not verified locally.
- This ZIP retains the existing `tmomentum` package version `1.0.2` and
  package/import names. Install in a separate virtual environment from the
  corrected variant; do not upload both versions to PyPI under the same version.
